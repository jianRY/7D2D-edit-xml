七日杀配置编辑器 · 使用说明
================================

【版本】v2.0（2026-08-03 版本升级）

【v1.0.1 重要修复 —— 若你用 v1.0 改过配置，请务必看这段】
v1.0 存在一个会导致「改完配置后服务器起不来」的严重 bug：

  程序保存时会沿用「读取时猜到的文件编码」写回。如果你的
  serverconfig.xml 曾被记事本以「ANSI」编码保存过（中文服主很常见），
  文件实际是 GBK 编码，而 serverconfig.xml 按 XML 规范必须是 UTF-8。
  于是服务器读取时报 XML 格式错误，直接启动失败。

v1.0.1 的修复：
  1. 无论源文件是什么编码，一律以 UTF-8 写回（GBK 文件会被顺带修复）。
  2. 新增写盘前 XML 合法性校验：只要生成的内容不是合法 XML，
     就拒绝写入并弹窗报错，原文件保持不动。从根上杜绝配置被写坏。
  3. 端口等数字项、枚举项、路径项以及沙盒预设码，写入前自动去除
     首尾空白（从网页复制 SandboxCode 常带换行，也会让服务器解析失败）。

已经中招怎么办（二选一）：
  · 用 v1.0.1 重新打开那个 serverconfig.xml，随便改一项再改回来后保存，
    文件会被自动修正为 UTF-8；
  · 或到 serverconfig.xml 同目录的「配置备份」文件夹，
    用「备份 → 还原」挑一份出问题之前的备份恢复。


【v1.0.2 修复 —— 改动确认对话框按钮不可见】
v1.0.1 的「保存前改动确认 / 查看改动对比」对话框存在布局缺陷：
可滚动的改动清单区域会吞掉全部剩余空间，把窗口底部的
「确认保存 / 取消」按钮挤到可视区之外，必须手动缩放窗口才能看到按钮。

v1.0.2 的修复：
  1. 按钮栏改为贴底固定（side=bottom），永远显示在窗口底部可见区域。
  2. 改动清单放在中间剩余空间并保留滚动，长清单不再把窗口撑爆。
  3. 设置窗口最小尺寸 560×360，避免小屏 / 高分屏下按钮被压没。
（如果你之前因看不到按钮而无法保存，升级到 v1.0.2 即可正常操作。）


【v1.0.3 修复 —— 保存时会写入服务器不支持的属性导致起不来】
v1.0.2 及更早版本会在保存时把「存档目录（SaveGameFolder）」写进 serverconfig.xml。
但《七日杀》V3.1 的 serverconfig.xml 并不支持 SaveGameFolder 这一项（它是启动
命令行参数 -savegamefolder，不是配置文件项）。服务器读到这个不认识的项会直接报
「Unknown config option」并中止启动。这个 bug 在 v1.0.1 修复 GBK 编码后才暴露——
之前文件因编码损坏整体解析失败，根本走不到这一行；编码修好后文件能正常解析，
这个非法属性才被服务器发现。

v1.0.3 的修复：
  1. 从设置项里彻底移除「存档目录（SaveGameFolder）」配置，界面不再提供它。
  2. 保存时增加「剥离」机制：无论原文件里有没有 SaveGameFolder，保存后都会
     从 serverconfig.xml 中删除该项（连同工具生成的注释行），确保写出的配置
     服务器一定能解析。合法且更常用的「用户数据目录（UserDataFolder）」保留不变。
  3. 如果你用 v1.0.2 或更早版本改过配置、服务器现在起不来，用 v1.0.3 重新打开
     那个 serverconfig.xml 保存一次即可自动修好；或到「配置备份」文件夹还原。

（注：想自定义存档位置，请用启动命令行参数 -savegamefolder "你的路径"，
而不是写在 serverconfig.xml 里。）


【简介】
七日杀配置编辑器是一个专门用于读取和修改《7 Days to Die》（七日杀）
官方专用服务器配置文件 serverconfig.xml 的桌面工具。
全程中文界面，设置项非常详细（专用于《七日杀》V3.1「Henpocalypse」官方配置，共 70 项可编辑配置，
分 18 大类；难度 / 血月 / 战利品等约 165 项玩法由 SandboxCode 统一控制），
保存时自动备份原文件，可随时一键还原。旧文件里残留的已失效属性会归入「未识别配置」并原样保留，不会误改。

本程序是“单文件 exe”，无需安装 Python，双击即可运行（仅支持 Windows）。


【它能做什么】
· 读取任意 serverconfig.xml（官方样例、自己改过的、模组自定义的都行）。
· 用中文分类表单修改每一项配置；被注释掉的示例项不会被误当成生效项。
· 保存时只改 value 部分，原文件的注释、缩进、换行、编码全部原样保留。
· 自动生成带时间戳的备份（最多保留 50 份），支持还原 / 删除备份。
· 内置配置体检：端口冲突、世界尺寸非法、槽位矛盾、跨平台联机前置条件、
  Modded 标记提醒等会主动提示。
· 5 套玩法预设（休闲PvE / 标准生存 / 硬核 / PVP / 低配机器）一键套用。
· 顶部搜索框可按中文名 / 英文键名模糊过滤；改动过的高亮显示。
· 命令行体检模式：七日杀配置编辑器.exe --check 配置文件.xml（只读不写）。


【首次使用 · 三步走】
1) 打开文件
   启动后点「文件 → 打开配置」选择你的 serverconfig.xml；
   或直接把文件拖到窗口（若支持）。
   程序也会尝试自动查找常见位置的服务器配置。

2) 修改配置
   左侧选分类（如「网络与端口」「世界与地图」「僵尸与血月」），
   右侧改对应表单。改过的项前会有蓝色圆点并标蓝，方便核对。
   想批量套用玩法，点「预设 → 选择玩法」挑一套即可。

3) 保存
   点「保存」（Ctrl+S）。保存前会自动备份原文件到同目录的
   「配置备份」文件夹，命名形如 serverconfig.xml_20260801_174500。
   保存前会弹出改动清单确认对话框，核对无误点确定即可。


【仅支持 V3.1（Henpocalypse）】
本工具专用于《七日杀》V3.1「Henpocalypse」（2026-07-27 转正式版）的 serverconfig.xml，
不再提供 V1.3 / V2.0 / V2.6 / V3.0 的历史版本切换与适配，打开文件直接按 V3.1 解析。
· V3.1 的玩法入口是 SandboxCode：难度 / 经验 / 血月 / 战利品 / 昼夜等约 165 项玩法
  已统一收进这一个字符串。它必须由游戏内「沙盒选项」菜单生成，或粘贴在线生成器
  给出的码，再填到 SandboxCode 这一项里；单独改下面的旧项在 V3.1 无效。
· ⚠ V3.1 旧码漂移：V3.1 移除了 3 个生成选项并复用了其槽位，导致 V3.0 生成的旧码
  在 V3.1 服务器上不报错、却静默套用成一整套「不同的规则」。若你的服务端已升级到
  V3.1，请务必重新生成 SandboxCode，不要用 V3.0 时代留下的旧码。
· 工具内置多个「SandboxCode 在线生成器」入口，可任选其一：顶栏「🌐 SandboxCode 生成器 ▾」
  下拉按钮、菜单「工具 → SandboxCode 在线生成器 ▾」（级联列出全部）、以及「沙盒预设码」
  页面顶部的「🌐 选择 SandboxCode 在线生成器 ▾」按钮条——点开即展开 5 家生成器
  （Host Havoc / GhostCap / PingPerfect / 7d2d.net / Game Host Bros），选哪家就打开哪家，
  调好玩法后把生成的码粘回 SandboxCode 即可（均为客户端运行，不泄露你的配置）。

【界面导览】
· 顶部：搜索框（按名称 / 键名过滤）、菜单栏。
· 左侧：分类导航树（18 个大类，可折叠展开）。
· 右侧：配置表单。每行含「中文名」「说明(悬停提示)」「当前值控件」。
   - 开关项：开启 / 关闭 下拉。
   - 枚举项：下拉候选。
   - 数值项：数字框 + 单位（天 / 小时 / 米 / 倍率…）。
   - 密码项：服务器密码，可点眼睛图标切换明文/密文。
   - 路径项：文本框 + 选择按钮。
· 菜单：
   - 文件：打开配置 / 另存为 / 退出。
   - 操作：保存(已改动项确认) / 还原上一份备份 / 配置体检。
   - 预设：休闲PvE / 标准生存 / 硬核 / PVP / 低配机器。
   - 备份：打开备份目录 / 还原 / 删除旧备份。
   - 视图：XML 预览（直接看改完的原文）。


【自动备份机制】
· 保存时会先把“改动前的原文”复制到「配置备份」目录（时间戳命名）。
· 还原某份备份前，也会先备份当前版本，绝不丢数据。
· 备份最多保留 50 份，超出自动清理最旧的。
· 备份目录位置：与被打开的 serverconfig.xml 同级，名为「配置备份」。


【配置体检（校验）会查什么】
· 类型 / 取值范围错误（如天数填成负数）。
· 端口冲突（游戏端口与管理端口重合）。
· 世界尺寸非法（必须小于 10240 且为合法半径等）。
· 槽位矛盾（ServerMaxPlayerCount 与 EAC / 跨平台设置冲突等）。
· 跨平台联机前置条件（Crossplay 开启时需要的配套项）。
· Modded 标记提醒（装了模组应把 ServerIsModded 设为 true，便于联机匹配）。
点「操作 → 配置体检」即可查看告警清单，分错误/警告两级。


【玩法预设说明】
· 休闲PvE：友好领地、离线家无敌、禁止误伤玩家。
· 标准生存：贴近官方默认服务端参数（领地、创造模式）。
· 硬核：缩小保护区与安全区（高强度玩法请在 SandboxCode 里设定）。
· PVP：开启 PVP、限制第一人称、防秒退掉落。
· 低配机器：缩小世界、降动态网格距离、压低僵尸数，省性能。
预设只覆盖服务端层面的常用项（难度 / 血月等玩法强度请在 SandboxCode 里设定），
其余项目保留你当前文件里的值。


【命令行体检】
适合无图形界面的机房 / 云服务器做快速检查：
   七日杀配置编辑器.exe --check D:\7DaysToDieServer\serverconfig.xml
只读不写，输出告警清单后退出。


【端口与联网】
· 默认游戏端口 26900（UDP/TCP），需在防火墙 / 路由器放行。
· 想让服务器出现在公共服务器列表，需填写 ServerLoginToken
  （从 7daystodie.com 官网获取）。
· 跨平台联机（PC/主机）请开启 Crossplay 并留意体检提示的配套项。


【常见问题】
Q：打开文件后某几项显示成英文 / 没说明？
A：这是官方尚未收录或你模组自定义的配置项，工具会原样保留其值，
   不影响保存。可在「视图 → XML 预览」里核对原文。

Q：保存后原文件注释丢了？
A：不会。本工具只定点替换 value，注释、缩进、换行、编码都原样保留。

Q：改错了想撤销？
A：点「备份 → 还原」，选最近一份备份即可。还原前也会再备份当前版本。

Q：配置改了服务器里不生效？
A：确认保存的是服务器目录里那一份 serverconfig.xml，且保存后再启动 /
   重启服务器（七日杀只在启动时读取该文件）。

Q：能直接拖文件进窗口吗？
A：支持，把 serverconfig.xml 拖到程序窗口即可打开（部分系统需先启动程序）。

Q：我的是 V3.1 服务器，为什么难度 / 血月那些项改了没用？
A：V3.1 把难度、经验、血月、战利品等玩法（约 165 项）统一收进了 SandboxCode，
  原来的旧项（GameDifficulty、BloodMoonFrequency…）已失效、写了也无效。
  请改用 SandboxCode：在游戏内「沙盒选项」菜单调好玩法后复制生成码，
  或点顶栏「🌐 SandboxCode 生成器 ▾」选一家在线生成器出码，粘贴到 SandboxCode 这一项。
  ⚠ 若服务端是从 V3.0 升级上来的，务必重新生成 SandboxCode，旧码会静默套用成
  另一套规则而不报错。
